# Tomato-Lib
A library for SillyTavern extension developers, it contains a lot of utilities to avoid repeated code across several extensions. As an extension developer myself, I have various snippets of code that are repeated between my many extension. This library is an attempt on getting rid of that over time.

## Features
The API `TomatoLib` is exposed to the `globalThis` so extensions can fetch everything this library offers.

## Installation
Install the extension using this link inside SillyTavern's extensions installer: `https://github.com/leandrojofre/SillyTavern-Tomato-Lib.git`

## Support and Contributions
Feel free to add any utility you find it could be useful for eithers others or yourself. As a rule of thumb, try adding things you know you would use in several extensions even if their topics are related.

## Contribution Rules
- Always PR to the `staging` branch.
- If you create a new branch to work on your feature, make sure you use the `staging` branch as the source of your new branch.
- Nothing else really, enjoy.
